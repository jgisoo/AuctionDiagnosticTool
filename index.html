Diagnostic Dashboard | Criteo Internship Project

Built during my Software Developer Internship • Internal tooling for engineers & tech support

Project Overview

This project improves visibility into auction outcomes and SKU eligibility by expanding the internal diagnostic dashboard used by developers and technical support. It helps teams understand why certain SKUs do or do not serve, without needing to manually query data.

The Problem

  • Developers lacked visibility into auction decision logic
  • Difficult to diagnose why expected SKUs were not served
  • Engineers needed to manually query logs & pipelines
  • Existing diagnostic page lacked structured breakdowns

Project Goal

  • Provide a richer, structured diagnostic page
  • Surface auction + SKU eligibility data in one place
  • Reduce investigation time for dev & TS teams
  • Help new engineers understand pipeline behavior

My Contributions

  • Implemented new Razor Pages(C# + HTML) UI sections & data bindings (.NET)
  • Added expandable SKU lists (delivered / ineligible)
  • Created SP-only filtering logic in placements panel
  • Integrated tooltips, icons, and visual status signals
  • Improved clarity of metrics & diagnostic context
  • Collaborated with engineers to understand backend pipeline

Technical Stack

ASP.NET Razor Pages C# Models Bootstrap UI Diagnostics Data Expandable Components

This project improved my understanding of:

  • Backend data models & SKU pipelines
  • Razor binding & component structure
  • Collaboration across engineering teams

Impact

  • Faster debugging of auction behavior
  • Reduced manual data investigation effort
  • Better transparency for engineers
  • More intuitive diagnostic workflow
